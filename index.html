Privacy Policy — Klipper sirG

Effective date: 25 November 2026 · Operator: Gilang (individual) · Contact: gilangrmdn613@gmail.com

What this application is

Klipper sirG is a personal automation tool operated by a single individual. It prepares short video clips from livestream recordings and uploads them to the operator's own YouTube channel ("sirG ch", @klipperawigwogs) using the official YouTube Data API v3.

What data the application accesses

Through Google OAuth, the application requests only two scopes:

  • youtube.upload — to upload video files and set their titles, descriptions, and privacy status on the operator's own YouTube channel.
  • youtube.readonly — to read the operator's own channel information (channel ID and title) so uploads go to the correct channel.

The application does not access any other Google services, does not read email, contacts, files, or any data belonging to other people, and is not offered to the public as a service.

What data is stored

  • The OAuth refresh token issued for the operator's own account, stored in secure credential storage and used only to perform the uploads described above.
  • The video files and metadata (titles and descriptions) that the application itself creates for upload.

No personal data is sold, rented, shared with third parties, or used for advertising. No data is used to train machine-learning models.

Limited Use disclosure

Klipper sirG's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access immediately stops the application from using the YouTube API. To request deletion of any stored data, contact the operator at the email above; requests are handled within 30 days.

Changes to this policy

If this policy changes, the updated version will be published at this same URL with a new effective date.
